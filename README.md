# IHA Clean Viewer

Статическая страница для GitHub Pages, которая выдаёт bookmarklet для удаления GIF-слоя поверх медиа на `www.iha.ee`.

## Публикация

1. Создайте GitHub-репозиторий и загрузите содержимое этой папки в ветку `main`.
2. В настройках репозитория откройте **Pages** и выберите источник **GitHub Actions**.
3. Запушьте изменения — workflow из `.github/workflows/deploy-pages.yml` опубликует страницу.

После публикации откройте сайт, перетащите кнопку `IHA: очистить медиа` в панель закладок браузера и используйте её на IHA.ee.

## Принцип работы

GitHub Pages — это статический хостинг. Браузер не позволяет странице с другого домена менять DOM `iha.ee` в iframe. Bookmarklet выполняется только после явного нажатия пользователем на самой странице IHA и удаляет GIF-изображения из структуры `a div img[src*=".gif"]`. Имя файла не используется, поэтому смена имени GIF не требует обновления проекта. Он не отправляет данные, не работает с учётной записью и не загружает медиа через этот проект.

## Структура

```
.
├── .github/workflows/deploy-pages.yml  # автоматическая публикация

│   └── styles.css                       # стили
├── .nojekyll                            # отключает обработку Jekyll
├── index.html                           # главная страница
└── README.md
```
