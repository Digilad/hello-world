# IHA Clean Viewer

Статическая страница для GitHub Pages, которая выдаёт bookmarklet для удаления GIF-слоя поверх медиа на `www.iha.ee`.

## Публикация

1. Создайте GitHub-репозиторий и загрузите содержимое этой папки в ветку `main`.
2. В настройках репозитория откройте **Pages** и выберите источник **GitHub Actions**.
3. Запушьте изменения — workflow из `.github/workflows/deploy-pages.yml` опубликует страницу.

После публикации можно использовать один из двух вариантов:

- **Bookmarklet:** откройте сайт, перетащите кнопку `IHA: очистить медиа` в панель закладок браузера и нажимайте её на IHA.ee.
- **Автоматически:** установите Tampermonkey или другой менеджер userscript, затем откройте `scripts/iha-clean.user.js` на опубликованном сайте и подтвердите установку. Скрипт запускается на каждой странице IHA.

## Принцип работы

GitHub Pages — это статический хостинг. Браузер не позволяет странице с другого домена менять DOM `iha.ee` в iframe. Поэтому bookmarklet выполняется после явного нажатия на IHA, а userscript — автоматически после его установки в браузер. Оба варианта ищут GIF-изображения в структуре `a div img[src*=".gif"]`, но удаляют их, только если родительский `div` уже содержит основное изображение как CSS-фон. Имя файла не используется, поэтому смена имени GIF не требует обновления проекта. Скрипт не отправляет данные, не работает с учётной записью и не загружает медиа через этот проект.

## Структура

```
.
├── .github/workflows/deploy-pages.yml  # автоматическая публикация
├── assets/
│   ├── app.js                           # bookmarklet и интерфейс
│   └── styles.css                       # стили
├── .nojekyll                            # отключает обработку Jekyll
├── index.html                           # главная страница
├── scripts/iha-clean.user.js            # автоматический userscript для IHA
└── README.md
```
